# Clipador — download

Corta automaticamente os melhores momentos das lives (Twitch/Kick), escolhe os melhores com IA e posta no TikTok, Instagram e YouTube Shorts.

## Como instalar (Windows 10/11)
1. Vá em **[Releases](../../releases/latest)** e baixe o arquivo **`Clipador-Setup-x.x.x.exe`**.
2. Clique duas vezes no arquivo e siga o instalador (Avançar → Instalar).
   - Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. Abra o **Clipador** pelo atalho na Área de Trabalho.
4. Siga o **tutorial da tela Início**: ativar a licença, instalar componentes, colar a chave da IA, entrar nas contas, escolher os streamers e clicar em **Iniciar tudo**.

## Licença
O Clipador precisa de uma **chave de licença**, presa ao seu computador. Abra o app → aba **Licença** → copie o **ID deste computador** e mande pelo WhatsApp para receber sua chave.
